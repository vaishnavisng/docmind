# DocMind AI Frontend

A modern React 19 + TypeScript + Tailwind CSS v4 frontend for the **DocMind AI** document intelligence platform.

* **Author:** Vaishnavi Singh ([@vaishnavisng](https://github.com/vaishnavisng))

---

## Getting Started

```bash
cd frontend/docmind-frontend
npm install
npm run dev        # http://localhost:3000
npm run build      # production build → dist/
```

The dev server automatically proxies `/api` → `http://localhost:8081`.

---

## Deployment on Vercel

Configured for zero-config Vercel deployment with `vercel.json` for client-side routing and API proxying.
